## 3. 开发约定（AGENTS.md / DEVELOPMENT.md 核心）

- 插件化：新功能优先 plugins/official/*（register(api) 自声明），核心只读服务放 core/dashboard-services.js（owner=core）
- 插件契约 v1.1：6 个 API 面；插件不能碰 ctx/core 表；api.db 只能 plg_<name>_ 前缀
- 破坏性操作走 api.tools.call（安全模式自动拦截）；dashboard 路由的破坏性操作（watchlist remove、tracked remove、moderation delete、favorites move/group 的破坏性分支）需显式检查 snapshot.safeMode
- 前端：Vue3 + PrimeVue SFC，`plugins/official/web-dashboard/ui/`，构建 `npm run build` → dist/index.html（单文件，~1.4MB）
- 路由注册：api.http.registerRoute（重复 path 会抛错）；插件路由在 plugins/official/web-dashboard/index.js + server/routes/*
- 测试模板：test/test-dashboard-services.test.mjs（服务）、test/dashboard-util.test.mjs（前端 utils 纯函数）
- Vue 模板注意：ref 自动解包，模板里不要写 `xxx.value.`（ChartsView 踩过坑）；v-model 不能绑表达式
