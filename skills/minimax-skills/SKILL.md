# MiniMax Agent Skills

Production-ready skills designed to elevate agentic coding and artifact generation to professional standards.

## Capabilities & Workflows

### 1. High-Polish Fullstack & UI Development
- Build rich, modern, responsive user interfaces with zero visual clutter.
- Implement clear typography hierarchies, consistent color palettes, and accessible interaction states.
- Ensure cross-platform compatibility across desktop, tablet, and mobile browsers.

### 2. Document & Report Generation
- **PDF Generation**: Structure clean print-ready reports with headers, footers, page numbering, and data tables.
- **Excel/XLSX Data Exports**: Format spreadsheets with bold headers, autofit column widths, styled cells, and summary formulas.
- **Structured Markdown Artifacts**: Produce visually appealing documentation with diagrams, callout alerts, and code diffs.

### 3. API & Multimodal Integration
- Integrate REST, WebSocket, and SSE endpoints with automatic reconnection and error recovery.
- Handle file streams, media attachments, and image previews safely.
- Implement resilient retry policies with exponential backoff for external API calls.

### 4. Production Quality Checklist
- [ ] No hardcoded credentials or secrets.
- [ ] Comprehensive error boundaries preventing app crashes.
- [ ] Clean, idiomatic code adhering to project-specific styling.
- [ ] Zero lint/build errors and all tests passing.
